## 🎯 ¿Para qué me lo pidió el profesor?

El docente **Gian Franco Denaro** solicitó estas investigaciones (con fecha de entrega el 13/11) con el objetivo de integrar los contenidos teóricos clave de 7.º año y demostrar cómo se complementan en el ciclo de vida real de un proyecto de software:

* **Dominar herramientas de análisis y diseño:** Diferenciar y aplicar tanto el enfoque estructurado (DFD, DER, Modelo Ambiental y de Comportamiento) como el orientado a objetos (UML 2.5.1, Casos de Uso, Diagramas de Clases y Proceso Unificado).

## 🏁 Conclusión

El desarrollo de un sistema informático exitoso no depende únicamente de escribir buenas líneas de código, sino de combinar análisis, modelado, planificación y documentación. A lo largo de estas dos investigaciones queda claro que cada herramienta cumple un rol específico y complementario: los diagramas permiten visualizar y validar la solución antes de construirla, la programación orientada a objetos organiza el código de forma mantenible, la planificación (PERT/Gantt y Proceso Unificado) ordena el esfuerzo del equipo, y una buena documentación asegura que el software pueda ser utilizado y mantenido en el tiempo. Dominar esta metodología integral prepara el terreno para afrontar proyectos reales de manera organizada y profesional.
